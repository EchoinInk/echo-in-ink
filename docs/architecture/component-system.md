# Echo in Ink — Component System

## Philosophy

Components are atmospheric primitives. They create consistency across the Echo in Ink ecosystem and act as the structural language of identity, systems, and worlds.

## Core Components

### AtmosphereCard

Editorial containers for philosophy, studio statements, and quiet content.

### SystemCard

Used for Identity Canvas, AI systems, frameworks, and intelligent tools.

### WorldCard

Entry points into Studio, Worlds, Works, and Lumo experiences.

### FeaturedWorld

Large cinematic feature component combining narrative and imagery.

### SignalPanel

Structured presentation of principles, frameworks, and signals.

### OrbitalVisual

Symbolic visual primitive representing systems, identity, and connection.

### ReflectivePrompt

Used for manifesto moments, philosophy, and archive writing.

### MonogramField

Brand atmosphere component for EI identity moments and hero compositions.

### GlowAnchor

Small signal marker for metadata and system indicators.

## Component Rules

- Use semantic props.
- Use shared tokens.
- Avoid one-off visual systems.
- Respect accessibility and reduced motion.
