# Echo in Ink — Layout System

## Philosophy

Layout should feel composed, cinematic, and spacious.

The rhythm:

Arrival → Orientation → Depth → Proof → Invitation

## Principles

Use:

- Negative space
- Editorial pacing
- Intentional asymmetry
- Strong hierarchy

Avoid:

- Dense layouts
- Generic grids
- Filling every space

## Section Types

Hero — emotional arrival

Intimate — philosophy and reflection

Standard — content and systems

Expansive — cinematic transitions

Pause — manifesto moments

Closing — final invitation

## Mobile

Mobile is an intimate experience, not a compressed desktop layout.

Prioritise readability and calm atmosphere.

## Principle

Space is part of the identity.
