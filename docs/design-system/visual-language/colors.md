# Echo in Ink — Color System

## Philosophy

The palette should feel cinematic, authored, and quietly luminous.

## Foundation

```css
--ei-void: #05030B;
--ei-ink: #080718;
--ei-midnight: #0B0D2A;
```

## Accent Roles

**Halo Blue**
Signal, focus, interaction, clarity.

**Violet**
Depth, atmosphere, worldbuilding.

**Echo Magenta**
Emotion, identity moments, emphasis.

## Typography

Ice White:
primary headings.

Moonlit:
body copy and supporting text.

## Rules

Do:

- Let accents behave like light
- Protect contrast
- Keep gradients subtle

Do not:

- Make every element glow
- Use pure white everywhere
- Let magenta dominate

## Principle

A dark world.
A soft signal.
A luminous atmosphere.
