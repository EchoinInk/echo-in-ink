# Echo in Ink — Atmosphere Guidelines

## Philosophy

Atmosphere is emotional context.

It should feel like cinematic weather: subtle, spacious, and intentional.

## Materials

Built from:

- Gradients
- Glows
- Grain
- Vignettes
- Light fields
- Image overlays

Every atmospheric effect needs a purpose.

## Glow Rules

Use glow for:

- Hero moments
- EI monogram
- Featured worlds
- Important interactions

Avoid glowing every component.

## Motion

Atmospheric motion should feel like breathing.

Use:

- Slow drift
- Gentle reveals
- Soft luminance changes

Avoid:

- Busy animation
- Constant movement

## Mobile

Clarity first.
Atmosphere second.
Decoration last.

## Final Rule

If atmosphere becomes the content, reduce it.
