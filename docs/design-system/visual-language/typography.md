# Echo in Ink — Typography System

## Philosophy

Typography translates atmosphere into language.

## Font Roles

## Fraunces

Soul.

Used for:

- Hero headlines
- Manifestos
- Emotional statements

## Neue Montreal

Clarity.

Used for:

- Body copy
- Navigation
- Interfaces
- Descriptions

## Geist Mono

System intelligence

Used for:

- Labels
- Metadata
- Classifications

## Hierarchy

Label — Geist Mono
Heading — Fraunces
Body — Neue Montreal
CTA — Neue Montreal

## Principle

The words should feel authored, not templated.
